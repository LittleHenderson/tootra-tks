# Appendix: Expression Building Tools

## Quick Reference: Complexity Levels

### Level 1: Single Element
- Format: `Xn^k_{mf}`
- Example: `A1^2_{1a}`
- Use: Simple states or qualities

### Level 2: Two Elements
- Format: `Xn^k ○ Yn^k`
- Example: `A1^2 + B2^2`
- Use: Basic relationships

### Level 3: Three+ Elements
- Format: `(Xn ○ Yn) ○ Zn`
- Example: `(A1 + B2) × C3`
- Use: Complex relationships

### Level 4: Multi-Operator
- Format: Mixed operators with grouping
- Example: `[(A ∩ B) + C] × D ÷ E`
- Use: System interactions

### Level 5: System Level
- Format: Multiple related expressions
- Example: Complete RPM trees
- Use: Comprehensive models

### Level 6: Meta Level
- Format: Self-referential or recursive
- Example: Expressions about expressions
- Use: Consciousness, philosophy
