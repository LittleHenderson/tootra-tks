  3. Replace the URL with the code below
  4. Save. Now tap that bookmark on any page to load HvrTwk

Features

  • Floating dark-glass pill -- drag up/down, tap to open controls
  • Desktop: hover over text, ring fills, text is read aloud
  • Phone: hold + draw a circle around text to hear it
  • Continuous mode: reads from your selection through the rest of the page
  • Auto-scrolls and highlights the current paragraph in green
  • Progress bar shows how far through the page you are
  • Tap the pill or anywhere on the page to stop continuous reading
  • Karaoke mode: words highlight as they are spoken
  • Android chunked speech: avoids Chrome's 15-second cutoff bug
  • Keep-alive timer prevents Android from pausing speech
  • Voice picker sorted by device language
  • All settings saved to localStorage across sessions
  • Zero dependencies -- pure Web Speech API
Voice setup on Android: Settings > System > Language & input > Text-to-speech output. Install Google TTS or Samsung TTS for best results. You can download additional voice packs (different accents, languages) from the same settings screen.
